Embedded Systems: Purpose and Characteristics

Year 10 · OCR GCSE J277 · Specification 1.1.3 · 45 minutes

Learning objectives

  • Define an embedded system accurately.
  • Identify typical characteristics of embedded systems.
  • Distinguish embedded systems from general-purpose computers.
  • Apply the definition to unfamiliar real-world examples.

Success criteria

  • I can explain the dedicated function of an embedded system.
  • I can describe at least three typical characteristics, with suitable qualifications.
  • I can justify whether a device contains an embedded system using evidence.

Starter · 0–5 minutes

Consider a microwave, washing machine, traffic light controller and laptop. Which are designed for a dedicated function? Write a sentence explaining your choice.

Learn · 5–13 minutes

An embedded system is a computer system integrated into a larger device, designed to perform a specific function or limited set of functions.

Embedded systems often use sensors or other inputs, process information with a controller, and control an output. They may be designed for low power, low cost, or predictable timing, but these are not universal requirements.

Worked example: Smart thermostat

Input: temperature sensor → Process: controller compares the temperature with the target → Output: heating control.

Explain the difference between an embedded controller and a general-purpose laptop.

Independent application · 23–33 minutes

A smart irrigation controller receives information from a soil-moisture sensor and switches a water valve on or off.

Explain why it is an embedded system. Identify its input, processing and output, and describe two characteristics it might have. Explain why those characteristics are not universal to all embedded systems.

Need support? Open sentence starters

“This is an embedded system because…” · “Its input is…” · “Its output is…”

Extension challenge

Explain why the claim “all embedded systems must operate in real time” is incorrect.
