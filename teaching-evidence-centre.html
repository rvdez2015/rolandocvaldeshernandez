Learning objectives

Intended learning outcomes for a KS3 lesson on selection:

  • Explain how selection allows a program to make decisions.
  • Use if, elif and else to control program flow.
  • Write Boolean conditions using comparison operators.
  • Apply correct Python indentation, test outcomes and debug simple conditional programs.

Teaching approach and viewing prompts

  • Explanation and modelling: how selection is introduced and demonstrated through code examples.
  • Progression: how learners move from recognising conditions to constructing their own decisions.
  • Checking understanding: opportunities for questioning, prediction, testing and debugging.
  • Accessibility: use of clear vocabulary, manageable examples and scaffolding for different starting points.

These are prompts for reviewing the recording, not time-coded observations or external assessor judgments.

Reflection and next steps

My development priorities include dividing live coding into shorter episodes, incorporating frequent pupil practice and checking prior knowledge of variables, comparison operators and Boolean expressions before introducing more complex branches.

Carefully structured examples can provide access for learners who need additional support, while extension tasks involving multiple conditions and debugging encourage greater independence.
